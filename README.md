# Amazon Clone

A simple **Amazon homepage clone** built as a frontend practice project using **HTML and CSS**.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

The project focuses on recreating the basic layout, styling, product sections, and footer of Amazon's website.

## Project Structure

```text
Amazon Clone/
├── index.html
├── style.css
└── res/
```

## Purpose

This project was created for **frontend practice** to improve my understanding of:

* HTML structure and semantic elements
* CSS positioning
* Flexbox
* Spacing and sizing
* Colors, typography, and styling
* Hover effects
* Layout composition
